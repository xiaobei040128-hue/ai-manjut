# 常用充值网络模板

模板仅减少重复输入，不代表某个交易所账户已开通对应网络；实际地址和网络需与收款平台充值页一致。不会生成地址或私钥。

- UID 内部转账不选择链；支持资产以交易所实际界面为准：https://www.okx.com/en-eu/help/internal-withdrawal
- Binance 内部转账说明：https://www.binance.th/en/faq/crypto-deposit-%257C-withdrawal/5339fb7b2890419b8d995b8ffbaff965
- USDT 常用模板采用 Ethereum/ERC20、TRON/TRC20，依据：https://tether.to/en/supported-protocols/
- USDC 常用模板采用 Ethereum、Solana、Base、Arbitrum One，依据：https://developers.circle.com/circle-mint/supported-chains-and-currencies
- BTC 与 ETH 模板对应各自主网。旧配置不自动迁移或清除。

核对日期：2026-10-27。模板不是完整支持列表，也不自动查询实时网络可用性。
